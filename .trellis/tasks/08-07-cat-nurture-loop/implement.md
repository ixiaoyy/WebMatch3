## 重点验证

### 自动化

```powershell
pnpm --dir apps/web test -- ambient-game
pnpm --dir apps/web test -- ambient-storage
pnpm --dir apps/web test -- ambient-controller
```

最终只运行一次完整前端门禁：

```powershell
pnpm ci:web
```

### 必测规则矩阵

- 三条同种小鱼正确合成并只消耗最早三条；顺序任意。
- 混合鱼种和不足三条均不合成；第七个不匹配鱼触发失败重排。
- 合成优先于七格失败；其他鱼仍留在托盘。
- 多 seed、最高 60 条、退化随机源都能完整求解；首屏同种三条跨层。
- 每条大鱼都增加 `fishFedCount`；第 4、10、100 条仍能喂，不存在 full rejection。
- 第 3/6/9 条进入短暂休息序列；后续喂食可打断，永久计数不丢失。
- v3 迁移保留声音、植物时间、clear count、level、ID 单调性和旧喂食数量，且当前局变为合法 v4 小鱼群。
- 气泡、抚摸、找鱼、进食和休息不会覆盖主动作；姿态切换不存在透明帧。

### 浏览器验收

- `1440x900`：小鱼与大鱼尺寸反差清楚，聚拢与飞向猫咪的因果链一眼可读。
- `768x1024`、`390x844`、`320x568`、`320x240`：托盘、猫、植物和阶段物件无关键重叠或滚动条，目标至少 44px。
- 指针/触摸：搜索、轻点收集、拖到猫的提示、自动喂食和猫咪菜单均正常。
- 键盘：Tab、方向键、Enter、Space、F、Escape、菜单焦点恢复均正常。
- reduced-motion：没有聚拢/飞行/呼吸位移，但大鱼、进食姿态、阶段变化和播报均可理解。
- PiP/away：移动同一 DOM 子树，动画暂停或恢复不复制状态，返回后永久亲密进度正确。

## 审查门槛

- 实施前：用户审阅原始任务文档并明确同意开始；开发中按用户反馈把“鱼段”调整为“小鱼合成大鱼”。

- 只暂存本任务确认的生产代码、配置和正式位图；不暂存 `.trellis/qa/`、`design-qa.md`、截图或临时诊断产物。

## 回滚点

- Engine / v4 快照失败：停止 UI 接入，保留旧版本读取测试，精确回滚本任务类型与迁移改动。
- 合成表现失败但规则正确：保留 canonical `combined` 结果，暂时降级为静态大鱼 + 猫咪进食姿态。
- 新阶段位图不达标：保留阶段数据与动作差异，待合格透明位图后再启用环境物件。
