# 试玩问题优化

## Goal

修复 2026-08-05 实际试玩中发现的四项交互缺陷，使桌面和 320px 窄屏上的指针、触摸、键盘与小窗降级路径都可预测、可解释，同时保持现有安静、无计分 HUD、无操作压力的核心体验。

本任务先完成复现、根因确认和回归保护，再实施最小范围修复。用户于 2026-08-05 批准执行并纳入 R5；实现、聚焦回归、完整 CI 和核心玩法实玩均已完成，剩余环境限制记录在研究证据中。

## Requirements

### R0 — 先对齐源码与运行态

- 用当前工作区分别在干净的开发服务器和生产构建预览中复现四项问题，记录 URL、构建模式、视口、能力检测结果和控制台状态。
- 对小猫菜单和小窗两项先解释“当前源码已有关闭/隐藏分支，但试玩运行态仍异常”的差异；检查事件时序、Vue 离场过渡、当前文档、Service Worker/缓存和实际加载产物，不得凭截图盲改。
- 诊断只使用隔离测试会话，不清除用户真实浏览数据，不把临时日志或测试开关留在生产代码中。

### R1 — 鱼群命中必须准确且达到有效目标尺寸

- 每条已显影、可选择的鱼都必须有至少 `44×44px`、可独立到达的指针/触摸命中区域；视觉位图可以互叠，但一个目标的透明矩形不得截获另一条鱼的意图。
- 显影展开过程中和稳定后，按下与抬起都必须绑定到同一条鱼；一次手势最多产生一次选择或喂食，不得因位置动画选中邻鱼。
- 展开布局保持确定性、限制在安全场区，并且只属于 UI 投影；不得修改引擎中的 `pile`、`spread`、层级、阻挡关系或快照。
- 保留所有鱼可选择的既有规则、原生按钮语义、方向键导航、Enter/Space 选择、`F` 喂猫、可访问名称和 reduced-motion 等价状态。

### R2 — 小猫互动菜单生命周期一致

- 在桌面、`320×568` 和 `320×240` 中，用指针、触摸或键盘选择“摸一下”或“帮我抓鱼”后，菜单状态都同步关闭。
- 动作触发后菜单须立即停止命中并离开可访问树；如保留离场动画，DOM 最迟在既有 `180ms` 动画窗口结束时移除，期间不得遮挡或接收第二次操作。
- 焦点不得丢失或落到已移除节点；Escape、外部点击、PiP 文档移动和 reduced-motion 行为继续符合现有契约。
- 现有寻鱼拒绝、looking/travelling/guarding、守鱼和返回逻辑不变。

### R3 — 键盘空搜给出克制、可播报的反馈

- 当探照灯已移动但当前位置没有可选择的显影鱼时，Enter/Space 不改变游戏状态，并通过现有 polite live region 给出简短提示，例如“这里还没有照到小鱼，继续移动探照灯”。
- 不在每次方向键移动时播报，不重复制造高频提醒；下一次成功选择、喂食或其他游戏反馈应正常替换空搜提示。
- 空搜反馈只属于当前 UI 会话，不写入引擎或持久化快照。

### R4 — Document PiP 按真实能力降级

- 当当前窗口没有可调用的 `documentPictureInPicture.requestWindow` 时，不渲染“小窗”按钮，也不显示无意义警告。
- 当 API 存在但请求被拒绝或失败时，保留同一挂载界面和当前局，并在 live region 给出一次简短失败说明。
- 当 API 可用时，继续移动同一个已挂载 surface；不得创建第二个 Vue 应用或重开一局。
- 开发服务器、生产预览、普通页面和 PiP 当前文档的能力判断必须一致，避免旧缓存产物继续暴露失效控件。

### R5 — 小猫配对优先

小猫仍只从“当前隐藏且合法”的候选中选择，但排序改为：

1. 托盘已有两条同类的候选；
2. 托盘已有一条同类的候选；
3. 其他合法候选；

同一优先级继续使用现有离小猫起点最近的稳定排序。该改动不得自动选择、移除或喂食目标，也不得改变找不到候选、猫休息或猫已守鱼时的拒绝规则。

## Acceptance Criteria

- [x] AC0. 四项缺陷均有与当前源码和构建模式对应的可重复步骤；若某项仅由旧产物或缓存造成，记录证据并只修复真实交付链路。
- [ ] AC1. 在 `1280×720`、`320×568` 与 `320×240` 的重叠夹具中，每条显影鱼都有独立可达的 `44×44px` 命中区；展开开始、动画中和稳定后三个时点点击都只选择画面所指的鱼。
- [ ] AC2. 鼠标点击、粗指针轻触、拖鱼喂猫、方向键、Enter/Space 与 `F` 各执行一次且不串目标；canonical 坐标、阻挡元数据和快照结构没有变化。
- [ ] AC3. 两个小猫动作在三个目标视口及键盘/指针路径上均关闭菜单；离场期间不可交互且不在可访问树中，结束后无残留 menu/menuitem，焦点可继续使用。
- [x] AC4. 键盘空搜会更新 polite live region，但不选择鱼、不写存储、不在方向键移动时连续播报；随后成功动作能替换提示。
- [x] AC5. PiP API 缺失、对象存在但 `requestWindow` 不可调用、请求拒绝、成功打开与关闭五条路径均有验证；缺失/不可调用时无按钮，拒绝时状态可感知，成功时 DOM 与游戏会话身份保持不变。
- [x] AC6. 实际完成首次三消、清空整片鱼场进入下一片、构造满托盘并观察自动重开；植物累计进度、声音偏好和刷新后新局语义不回归。
- [ ] AC7. reduced-motion、无 hover、320px 无横向溢出、关键控制至少 44px、浏览器控制台无 warning/error。
- [x] AC8. 先通过相关单元测试，最终代码状态只运行一次 `pnpm ci:web` 并通过。
- [x] AC9. 确定性测试覆盖“两条同类 > 一条同类 > 其他合法鱼”、无匹配回退和现有拒绝路径；浏览器中小猫不再优先增加可避免的托盘风险。

## Constraints

- 遵守 `PRODUCT.md` 的安静体验：不增加分数、计时、任务、弹窗、数值关卡或持续 HUD。
- 交互投影留在 `features/game/ui`；只有证据证明规则缺陷时才触及纯引擎，且不得用 DOM 矩形重写 canonical blocker 规则。
- 新增方法需有方法级注释，说明用途、关键参数和返回结果。
- 不连接数据库，不新增或修改数据库迁移。

## Out of Scope

- 重做鱼、猫、植物或壁纸资产。
- 修改三消、七槽失败、喂食容量、植物成长或新局持久化规则。
- 新增 PiP polyfill、桌面程序、系统级置顶能力或第二个 Vue mount。
- 声称完成完整 WCAG 认证；本任务只验证列出的交互和可访问性路径。
